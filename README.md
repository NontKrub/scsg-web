# Saint Gabriel's Congress

Create a complete website 

S.C.S.G. / SGSC

Student Congress of Saint Gabriel's College

This is the official website of the Student Congress of Saint Gabriel's College.

The website must feel like a real student organization website, not a generic school website and not a corporate dashboard.

The design should be:

modern clean premium easy to understand

highly visual

minimal text

strong typography

image-focused

student-led but still formal enough to represent the school

responsive for desktop and mobile

organized clearly despite having many organizations and members

Use grey image blocks when real images are not available.

Do not write "placeholder" inside the grey blocks.

Do not create a personalized student dashboard.

Do not add future features.

Only design the features described below.

1. ABOUT SGSC

SGSC is the Student Congress of Saint Gabriel's College.

The Congress consists of approximately 68 student leaders from 4 main organizations:

Student Government

House of Saints

Clubs of Interest

Class Representatives

The website should visually communicate:

Main SGSC design should use:

Near-black

Light grey

SGSC itself should remain visually formal and neutral.

House pages are where strong House colors appear.

34. UI STYLE

Use:

Strong grid systems

Large whitespace

Editorial layouts

Large numbers

Thin divider lines

Subtle rounded corners

Simple icons

Minimal gradients

Very limited shadows

Avoid excessive glassmorphism.

Avoid excessive card layouts.

The website should feel designed, not like a default UI kit.

35. ANIMATION

FINAL GOAL

Design the website so that a Saint Gabriel's student visiting it for the first time can understand within seconds:

What SGSC is.

Who runs it.

How the four organizations connect.

What the Houses are.

Which House is currently leading.

What current projects are happening.

How to book SG Radio.

Who their representatives are.

It should be highly visual, modern, easy to navigate, and realistic enough to be developed as an actual production website.
